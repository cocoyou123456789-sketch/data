# ScienceOne silicon test kit

This folder contains a small, internally consistent silicon fixture for testing
the three ScienceOne panels in the ARPES website.

## Files

- `silicon-cubic-5.431.pkl`: cubic `Lattice` pickle generated by the official
  ScienceOne `cubicCrystalGen` tool with `lattice_parameter = 5.431`.
- `crystal-structure-request.json`: complete proxy request for
  `crystalStructureGen`.
- `silicon-diamond-structure.pkl`: successful structure output generated by the
  official ScienceOne `crystalStructureGen` tool.
- `crystal-structure-result.json`: the successful upstream response.
- `silicon-scf.in`: Quantum ESPRESSO `pw.x` SCF input for an eight-atom
  conventional diamond-silicon cell.
- `Si.pz-vbc.UPF`: official Quantum ESPRESSO silicon pseudopotential from the
  Original QE PP Library.
- `quantum-espresso-request.json`: complete proxy request for the Quantum
  Espresso job endpoint.
- `band-query-request.json`: example Materials Project band-query filters. This
  request needs a direct ScienceOne band-tool endpoint before it can run.
- `silicon.cif`: human-readable reference structure. The current
  `crystalStructureGen` endpoint does not accept CIF directly.

## Test the crystal-structure panel

1. Select `silicon-cubic-5.431.pkl` in the local file area.
2. Use this public URL:

   `https://arpes-materials-explorer-cocoyou.netlify.app/examples/scienceone/silicon/silicon-cubic-5.431.pkl`

3. Paste this species list:

   `Si, Si, Si, Si, Si, Si, Si, Si`

4. Paste these fractional coordinates:

   `[[0,0,0],[0,0.5,0.5],[0.5,0,0.5],[0.5,0.5,0],[0.25,0.25,0.25],[0.25,0.75,0.75],[0.75,0.25,0.75],[0.75,0.75,0.25]]`

5. Submit. A successful response contains a `structure_file_url`.

## Test the Quantum Espresso panel

1. Set calculation type to `SCF` and priority to `5`.
2. Select `silicon-scf.in` as the INPUT file.
3. Use this public INPUT URL:

   `https://arpes-materials-explorer-cocoyou.netlify.app/examples/scienceone/silicon/silicon-scf.in`

4. Select `Si.pz-vbc.UPF` as the pseudopotential.
5. Use this public UPF URL:

   `https://arpes-materials-explorer-cocoyou.netlify.app/examples/scienceone/silicon/Si.pz-vbc.UPF`

6. Submit the job. The INPUT references `Si.pz-vbc.UPF`, so the file names
   match exactly.

## Test the band-query panel

This panel does not accept files. Copy the values from
`band-query-request.json` into the form. The website proxy currently requires
ScienceOne's direct band-tool URL before this third request can run.

## Sources and scope

- Lattice and structure pickle files were generated by ScienceOne on
  2026-07-20.
- The UPF file comes from:
  `https://pseudopotentials.quantum-espresso.org/upf_files/Si.pz-vbc.UPF`
- These files are interface fixtures, not publication-grade convergence data.
  Production calculations require convergence testing and scientific review.
