FIELD GUIDE / 使用说明

Bring your material idea into space.

Camera gestures / 摄像头手势

Manual clicking is the default: moving over a station previews it, but selection changes only on a click. Use the mouse, trackpad or native Mac gesture cursor. Camera mode also accepts a deliberate pinch click on buttons, checkboxes and links, and pinch-drag on sliders. The optional one-second automatic hover selector starts disabled.

默认手动点击：移动光标不会自动切换线站，点击卡片、编号或设备才选中。可使用鼠标、触控板或 Mac 手势光标。网页摄像头模式下，捏合后松开可点击按钮、复选框和链接，捏合拖动可调整滑块；停留自动选择默认关闭。

Beamlines can be selected from their directory cards, model labels, or instrument geometry. With “Hover 1s to select a beamline” enabled, a progress bar fills before selection. Previous / Next and the Up / Down / Home / End keys navigate the directory. Hover selection also works with the Mac desktop gesture app's cursor; leave the webpage camera off when using that app.

左侧卡片、模型编号和线站设备都可以选择。开启“停留 1 秒选择线站”后，进度条填满即可选中；也可使用上一条／下一条或方向键、Home、End。使用 Mac 本地手势应用时，把桌面光标移到卡片上即可，网页摄像头保持关闭。

Click Enable camera gestures and allow camera access. Start with one open hand. Point with your index finger, pinch thumb and index finger and release to select a beamline or scene button. Hold the pinch over the model and move to rotate. Spread two hands apart to zoom in; bring them together to zoom out. Move the cursor to the top or bottom edge to scroll. Stop camera or Esc ends the session.

点击“开启摄像头手势”并允许摄像头访问。先张开一只手，食指移动光标；拇指和食指捏合后松开可选择线站。对着模型按住捏合并移动可旋转；双手拉开放大、靠近缩小。伸出食指和中指，指向列表后上下移动即可滚动；滚动时光标固定在目标区域。可调节“滚动速度”。“关闭摄像头”或 Esc 结束操作。

For the web camera, aim at a list, raise the index and middle fingers and move them up or down. The scroll target stays fixed while your hand moves. Adjust Scroll speed for long pages. In the native Mac app, Control + Option + S toggles continuous scrolling: move above or below the starting position, hold to continue, and return to center to stop.

Use an HTTPS page or localhost in a camera-enabled browser. Keep hands well lit and inside the preview. Video is processed locally using the bundled MediaPipe model. Switching away from the page stops the camera; enable it again when you return.

建议在 Chrome 或 Edge 打开网站，在明亮环境中把手放在预览画面内。识别在本机完成；切换到其他页面后摄像头会关闭，回来后重新开启即可。

1. Explore / 探索展厅

Switch between Light source, Beamline, Crucible and Atom model. Drag to orbit; ordinary wheel input scrolls the page, and Command / Control + wheel zooms the model. You can also use the camera buttons. Explode separates schematic components. The music-note button reads the current station text using browser speech support.

选择光源、光束线、坩埚或原子模型；拖动旋转，普通滚轮上下滚动页面，Command / Control + 滚轮缩放模型，也可使用按钮。拆解模式帮助观察组成部件。音符按钮可朗读当前展项。

2. Design / 设计材料

Drag an element into the scene, or click/tap it. Set relative ratios with the numeric controls. MgB₂, FeSe and YBCO are starting recipes. Undo restores the previous composition. Save recipe stores up to twelve recipes on the current browser and device. Download a research brief for a portable record.

拖入或点击元素，调整相对配比。支持撤销、保存最近十二份配方，以及导出包含参数的研究简报。本地保存不会跨浏览器自动同步。

3. Analyze & ask / 分析与研究

Analyze runs the existing local composition baseline. Formation energy and metallicity are estimates, not experimental results. The error shown is a held-out dataset statistic. Composition does not resolve a crystal structure. Atom positions and connections in the 3D grid are decorative: never use this scene as DFT input.

分析使用网站已有的本地成分基线，展示模型估算及适用域。三维原子网格没有经过晶体结构求解，不能直接用作 DFT 输入。光子能量与温度仅为计划值，并不控制设备。

Copilot recognizes add Cu 2, MgB2, analyze, tour, ring, beamline, crucible, crystal, reset and export. It also recognizes 添加、分析、导览、清空、导出. For free-form questions, Continue with Research Agent transfers the brief into the existing agent’s context field. Cloud calls require the existing authorized account. No model request is sent just by visiting this lab.

4. Blender / 把场景带入 Blender

Click Export to Blender to download a self-contained .gltf file. In Blender, choose File → Import → glTF 2.0 (.glb/.gltf), then choose the downloaded file. Meshes and materials are embedded, with named parts you can select and edit. The selected view (including exploded geometry) is exported; camera, browser lights, and UI are not.

点击导出得到包含几何与材质的 .gltf 文件。Blender 中选择“文件 → 导入 → glTF 2.0”，即可继续建模。导出的是当前场景几何，包括拆解效果；浏览器相机与 UI 不在导出范围内。这是文件交接，目前没有实时双向连接。
