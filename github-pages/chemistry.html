发展史与基础

理解同步辐射从加速器副产物到先进光源的演进。

5 个专题
◷

发展史与光源代际

从首次观测到衍射极限储存环

+
  • 1947 年电子同步加速器上首次直接观测可见同步辐射
  • 第一代寄生使用高能物理装置，第二代转向专用储存环
  • 第三代以插入件高亮度光源为核心，第四代走向衍射极限与自由电子激光
时间线光源代际大科学装置
⚡

辐射产生原理

相对论电子与磁场中的电磁辐射

+
  • 高速电子在弯转磁铁中改变方向并辐射能量
  • 扭摆器产生高通量宽谱，波荡器通过相干叠加获得高亮度窄谱峰
  • 电子能量、磁场周期和间隙共同决定光子能区
✦

同步光的关键特性

亮度、能量可调与时间结构

+
  • 高通量、高亮度和小发散角适合微区与弱信号研究
  • 连续可调光子能量实现元素选择性和共振增强
  • 偏振、相干性与脉冲结构支持磁性、成像和动力学实验
⌁

装置与束线系统

从电子源到实验站的完整链路

+
  • 注入器、增强器和储存环维持高品质电子束
  • 前端、狭缝、单色器与反射镜选择并整形光束
  • 样品环境、运动平台和探测器完成信号采集
◎

光与物质相互作用

材料化学信号从哪里产生

+
  • 弹性散射和衍射给出长程结构与形貌尺度
  • 吸收、荧光和发射过程揭示元素与局域配位
  • 光电子与共振过程连接占据态、未占据态和化学键

核心实验技术

按照“结构—局域环境—电子态—空间分布—动态过程”选择方法。

5 类技术
◇

衍射、散射与 PDF

长程有序到纳米局域结构

+
  • 粉末与单晶 XRD 确定物相、晶格和结构精修
  • SAXS/WAXS 与掠入射方法研究纳米尺度、薄膜和界面
  • 总散射与对分布函数 PDF 表征无序、非晶和局域畸变
∿

X 射线吸收谱

元素选择性的价态与局域配位

+
  • XANES 对氧化态、对称性和未占据电子态敏感
  • EXAFS 提取近邻原子种类、配位数、键长和无序度
  • 透射、荧光和电子产额模式适配不同浓度与样品形态
e⁻

光电子与软 X 射线谱

表面化学、成键与能带结构

+
  • XPS 定量元素组成、化学位移与表面反应
  • NAP-XPS 在气氛或近常压下追踪真实反应界面
  • ARPES/NEXAFS 研究能带、轨道取向和未占据态
⌗

成像与化学显微

把组成、价态和结构映射到空间

+
  • 微纳 XRF 映射痕量元素及其空间分布
  • 吸收、相衬和衍射衬度成像呈现内部三维结构
  • 谱学成像与断层扫描构建多维化学态分布
⏱

原位、操作态与联用

在工作条件下捕捉结构演化

+
  • 温度、压力、气氛和电化学池模拟真实环境
  • 时间分辨实验追踪相变、反应中间体和失效过程
  • XRD–XAS–PDF–Raman 联用建立跨尺度结构证据链

催化与表界面化学

活性位、吸附物种与反应路径

+
  • 操作态 XAS 识别活性中心价态和配位变化
  • NAP-XPS 追踪表面吸附物与反应中间体
  • 散射、成像和质谱联用连接结构与选择性

电池与能源转化

电极相变、界面膜与衰减机理

+
  • 操作态 XRD/PDF 解析充放电中的相变和无序
  • XAS/XPS 追踪过渡金属价态与界面化学
  • 三维成像识别裂纹、孔隙和锂分布不均
♧

环境与地球化学

痕量元素形态、迁移与固定

+
  • 微 XRF 定位土壤、矿物和颗粒中的痕量元素
  • XANES/EXAFS 判定污染物价态和结合形态
  • 原位池研究溶解、沉淀、腐蚀和长期演化
⌬

软物质与生物材料

自组装、层级结构与功能界面

+
  • SAXS/WAXS 解析聚合物、胶体和分子组装尺度
  • 时间分辨散射追踪结晶、相分离和加工过程
  • 软 X 射线谱研究药物、膜和生物界面化学
