重点谱学自动化工作流

MVP 优先落地 XAS + XPS，并为 APXPS 与多模态解释预留接口。

4 条流水线
Xμ

XAS 自动处理

sample.xmu → 氧化态与白线指标

+
  • 能量校准 → pre-edge/post-edge → 归一化 μ(E)
  • 提取 edge energy、white-line intensity 和参考谱相似度
  • 输出价态估计、处理参数、质量警告与可复现图表
χk

EXAFS 结构拟合

χ(k) → R-space → FEFF 路径

+
  • 选择 k 权重和窗口，完成傅里叶变换与路径筛选
  • 拟合键长、配位数、ΔE₀ 与 Debye–Waller 因子 σ²
  • 保存参数相关性、残差、约束和拟合版本
eV

XPS 化学态分析

txt/csv/xy → 峰组分与结合能位移

+
  • 能量校准、Shirley/Tougaard 背景和峰形选择
  • 按化学约束拟合自旋轨道双峰与组分面积
  • 输出价态比例、结合能位移、不确定度和拟合残差
P,T

APXPS 动态演化

压力、温度、电位与时间序列

+
  • 对齐 gas pressure、temperature、potential、time 元数据
  • 追踪吸附物、氧化物生成和反应产物的化学态变化
  • 以二维趋势图和事件节点连接表面重构与催化性能

分阶段建设路线

先形成可用闭环，再扩展计算与多模态 AI Scientist。

Phase 1 · MVP

XAS + XPS 闭环

材料输入、晶体结构展示、谱学文件上传、自动预处理、基础拟合与分析报告。建立可演示、可测试、可积累数据的最小产品。

Phase 2 · Simulation

DFT + FEFF 联动

加入 ASE/pymatgen 结构生成、VASP/QE 解析、FEFF 理论谱和实验—理论谱对齐，形成结构假设验证流程。

Phase 3 · AI Scientist

多模态机理推理

联合 XAS、XPS、DFT、TEM 与电化学，生成带证据引用、置信度和待验证假设的 Nature/JACS 风格机理说明。
